# OpenRGB: código-fonte e licença / source code and license

**Português**

Esta pasta traz o [OpenRGB](https://openrgb.org) 1.1, um programa separado, sem nenhuma alteração.
O Perialls só conversa com ele pela rede local (o "SDK Server"); o código dos dois não é misturado.

- Licença do OpenRGB: GNU GPL versão 2 (arquivo `LICENSE` nesta pasta).
- Código-fonte da versão exata incluída (OpenRGB 1.1, commit `8e16de2`):
  - anexado em cada Release do Perialls, no arquivo `OpenRGB-1.1-source.tar.gz`;
  - também em https://codeberg.org/OpenRGB/OpenRGB/src/tag/release_1.1
- O OpenRGB inclui bibliotecas de terceiros, como Qt 6 (LGPL-3.0), libusb (LGPL-2.1), hidapi
  (BSD/GPL-3.0), Mbed TLS (Apache-2.0), PawnIO (Windows) e outras bibliotecas do sistema (Linux),
  cada uma com a sua licença.

**Oferta por escrito:** por pelo menos três anos a partir de cada Release do Perialls, qualquer pessoa
pode pedir o código-fonte correspondente do OpenRGB ou de qualquer biblioteca incluída nesta pasta,
sem custo além do envio. Peça abrindo uma issue em https://github.com/arthurgdelima-dev/perialls/issues

**English**

This folder contains [OpenRGB](https://openrgb.org) 1.1, a separate program, unmodified. Perialls only
talks to it over the local network (the "SDK Server"); the code of the two is not combined.

- OpenRGB license: GNU GPL version 2 (`LICENSE` file in this folder).
- Source code of the exact version included (OpenRGB 1.1, commit `8e16de2`):
  - attached to every Perialls Release, in the `OpenRGB-1.1-source.tar.gz` file;
  - also at https://codeberg.org/OpenRGB/OpenRGB/src/tag/release_1.1
- OpenRGB includes third-party libraries such as Qt 6 (LGPL-3.0), libusb (LGPL-2.1), hidapi
  (BSD/GPL-3.0), Mbed TLS (Apache-2.0), PawnIO (Windows) and other system libraries (Linux), each under
  its own license.

**Written offer:** for at least three years from each Perialls Release, anyone may request the
corresponding source code of OpenRGB or of any library included in this folder, at no charge beyond
shipping. Ask by opening an issue at https://github.com/arthurgdelima-dev/perialls/issues
